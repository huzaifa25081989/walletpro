# WalletPro — Free Personal Finance App

## 📲 How to Get Your APK (FREE, 5 minutes)

### Step 1 — Create a FREE GitHub account
Go to https://github.com and sign up (free, takes 2 minutes)

### Step 2 — Create a new repository
1. Click the "+" button → "New repository"
2. Name it: `walletpro`
3. Set to **Public**
4. Click "Create repository"

### Step 3 — Upload all these files
1. Click "uploading an existing file" link
2. Drag and drop ALL the files from this folder
3. Make sure the folder structure is preserved:
   - `.github/workflows/build.yml`
   - `app/src/main/java/com/walletpro/MainActivity.java`
   - `app/src/main/assets/index.html`
   - `app/src/main/AndroidManifest.xml`
   - `app/src/main/res/values/styles.xml`
   - `app/build.gradle`
   - `build.gradle`
   - `settings.gradle`
   - `gradle/wrapper/gradle-wrapper.properties`
4. Click "Commit changes"

### Step 4 — Wait 3-4 minutes
GitHub will automatically build your APK!
Watch the progress: click "Actions" tab in your repository

### Step 5 — Download your APK
1. Click on the completed workflow run (green checkmark ✅)
2. Scroll down to "Artifacts"
3. Click "WalletPro-APK" to download
4. You get a ZIP file — extract it to get `app-debug.apk`

### Step 6 — Install on Android
1. Transfer the APK to your Android phone (WhatsApp, email, USB)
2. On your phone: Settings → Security → Enable "Unknown Sources" or "Install unknown apps"
3. Tap the APK file → Install
4. Done! WalletPro is on your phone! 🎉

## ✅ Features
- Dashboard with balance, income, expense charts
- Multiple accounts (bank, cash, savings, investment)
- Transactions — income, expense, transfer
- Categories with custom icons & colors
- Chart of Accounts
- Loans & debts tracker with interest
- Budget management with progress bars
- Reports — pie chart, bar chart, net worth
- Import CSV from Wallet by Budget Baker
- Backup & restore (JSON file)
- 100% offline, data stored on device only
- FREE forever, no ads, no account needed

## 🔒 Privacy
ALL data is stored 100% locally on your Android device using WebView localStorage.
Nothing is ever sent to any server. No internet connection needed after install.
